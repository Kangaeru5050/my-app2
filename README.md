# 3D Minecraft MVP

ブラウザ（HTML5 / CSS3 / JavaScript + Three.js）で動作するマインクラフト風ボクセルゲームのMVPです。
GitHub Pagesで自動公開されます。

## 特徴
- **完全スタンドアロン**: 外部アセット画像なし（Canvas APIによるプロシージャルドット絵テクスチャ）
- **プロシージャル地形生成**: 起伏のある丘陵地形、木（原木・葉）の自動生成
- **一人称視点操作**: PointerLockControlsによるスムーズな視点回転
- **ボクセル操作**: 左クリックでブロック破壊、右クリックでブロック設置
- **衝突判定 & 物理演算**: プレイヤーの重力、ジャンプ、ブロックとの当たり判定
- **効果音エンジン**: Web Audio APIによるプロシージャルサウンド（破壊音、設置音、ジャンプ音）
- **ホットバー**: 9種類のブロック（草、土、石、丸石、原木、葉、木材、レンガ、ガラス）

## 操作方法
- **移動**: `W` `A` `S` `D`
- **視点移動**: マウス操作
- **ジャンプ**: `Space`
- **破壊**: マウス左クリック
- **設置**: マウス右クリック
- **ブロック選択**: 数字キー `1` 〜 `9` または マウスホイール
- **ポインタ解除 / 一時停止**: `Esc`
